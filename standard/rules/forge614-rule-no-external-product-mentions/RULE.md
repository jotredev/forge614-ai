# Prohibido mencionar productos externos

> Como una marca que se explica por sí misma, sin señalar a la competencia.

**Regla.** Ningún nodo, contrato, especificación, documentación, README, comentario de código, mensaje de commit ni mensaje de producto menciona un producto, framework o proyecto externo como referencia o inspiración. Las decisiones se describen como propias de Forge614. La lista de términos prohibidos vive como dato en `standard/forbidden-mentions.json`, bajo control del propietario del ecosistema, no en esta regla.

**Alcance.** Código, documentación, contratos y commits de todos los repositorios del ecosistema. El propio archivo de datos (`standard/forbidden-mentions.json`) y `.superpowers/` quedan excluidos del escaneo.

**Por qué.** Forge614 es un producto propio; sus decisiones se explican por sí mismas y no por comparación con terceros (acta 0012).

**Verificación.** `validator: forbidden-mentions`.
