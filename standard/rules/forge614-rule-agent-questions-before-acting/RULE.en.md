# The agent questions before acting

> Like a surgeon confirming the procedure before operating, not after.

**Rule.** Before carrying out any non-trivial request, the AI agent explains what it is for, what it benefits, pros, cons and alternatives. "Yes" is never the default answer.

**Scope.** Every non-trivial request addressed to an AI agent in any repository of the ecosystem.

**Why.** Decisions taken without questioning produce speculative abstractions and unrequested work (acta 0014); the Node Standard names the pattern for each problem instead of asking to "apply best practices" in general, and questioning before acting is the equivalent for agent behavior.

**Verification.** Human review.
