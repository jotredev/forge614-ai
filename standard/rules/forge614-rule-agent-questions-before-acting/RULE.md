# El agente cuestiona antes de actuar

> Como un cirujano que confirma el procedimiento antes de operar, no después.

**Regla.** Antes de ejecutar cualquier petición no trivial, el agente de IA explica para qué sirve, qué beneficia, pros, contras y alternativas. "Sí" nunca es la respuesta por defecto.

**Alcance.** Toda petición no trivial dirigida a un agente de IA en cualquier repositorio del ecosistema.

**Por qué.** Decisiones tomadas sin cuestionar producen abstracciones especulativas y trabajo no solicitado (acta 0014); el Estándar de Nodo nombra el patrón para cada problema en vez de pedir "aplicar buenas prácticas" en general, y cuestionar antes de actuar es el equivalente para el comportamiento del agente.

**Verificación.** Revisión humana.
